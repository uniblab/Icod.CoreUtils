# SPLIT(1)

## NAME

**split** — split a file into pieces

## SYNOPSIS

```text
split [OPTION]... [FILE [PREFIX]]
```

## PATHNAME GLOBBING

Only the input `FILE` slot is eligible for Class B singular pathname globbing. A wildcard-bearing input must resolve to at most one pathname; an unmatched pattern remains literal and multiple matches are rejected. `PREFIX` is an output naming prefix and always remains literal, even when it contains `*`, `?`, or `**`.

## DESCRIPTION

`Icod.CoreUtils.Split` is a managed .NET implementation of GNU Coreutils `split(1)`, modeled on GNU Coreutils 9.11.

By default the command writes 1000-record pieces named `xaa`, `xab`, and so on. It can split by record count, byte count, bounded record-byte size, or GNU chunk specifications, with alphabetic, decimal, or hexadecimal suffixes.

The implementation protects against an output piece overwriting the input, including filesystem-identity alias detection when available.

## OPTIONS

```text
-a, --suffix-length=N          generate suffixes of length N
    --additional-suffix=S      append S to output file names
-b, --bytes=SIZE               put SIZE bytes in each output file
-C, --line-bytes=SIZE          put at most SIZE bytes of records in each file
-d, --numeric-suffixes[=FROM]  use decimal suffixes
-x, --hex-suffixes[=FROM]      use hexadecimal suffixes
-e, --elide-empty-files        omit empty outputs generated by --number
    --filter=COMMAND           send each piece to COMMAND; name is in FILE
-l, --lines=NUMBER             put NUMBER records in each output file
-n, --number=CHUNKS            generate N, K/N, l/N, l/K/N, r/N, or r/K/N layouts
-t, --separator=SEP            use SEP instead of newline; \0 selects NUL
-u, --unbuffered               flush each record in round-robin mode
    --verbose                  announce output files before opening them
    --help                     display command help and exit
    --version                  display version information and exit
```

## EXIT STATUS

```text
0    All requested pieces were produced successfully.
1    Usage, input, filter, or output processing failed.
130  The operation was cancelled.
```

## PLATFORM NOTES

`--filter` uses `/bin/sh -c` on Unix-like systems and the configured command processor on Windows, with the output piece name supplied in the `FILE` environment variable. Ordinary split data remains byte preserving.
