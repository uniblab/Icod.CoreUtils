# cp implementation

`cp` is the GNU-facing policy and diagnostic layer over the Batch 44 shared copy/move engine.

It supports source/destination classification, recursive E5 traversal, symbolic-link and hard-link policy, metadata and sparse-file preservation, reflink/copy-file-range opportunities, GNU backup and overwrite modes, update rules, E6 atomic replacement, destination-inside-source prevention, and controlled partial failures.
