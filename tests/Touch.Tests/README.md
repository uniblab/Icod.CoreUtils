# Icod.CoreUtils.Touch.Tests

This project exercises the Batch 36 `touch` implementation against the shared Completion Gate E3/E3R metadata and timestamp-mutation contracts.

Coverage includes missing operands, file creation and `--no-create`, explicit GNU date expressions, selective access and modification timestamps, `--time` selectors, reference files, reference-relative dates, POSIX `-t` timestamps, directories, symbolic-link no-follow behavior when the host supports it, diagnostics, help, and version output.
