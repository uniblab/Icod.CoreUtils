# Icod.DiffUtils.Shared tests

This directory contains tests for the reusable contracts and algorithms in `Icod.DiffUtils.Shared`.

- `ComparisonContractsTests.cs` covers suite-wide operands and exit statuses.
- `ThreeWayMergeTests.cs` covers two-way alignment details and the connected three-way regions consumed by `diff3` and future merge-oriented commands.
