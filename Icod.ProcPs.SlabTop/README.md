# Icod.ProcPs.SlabTop

This project implements the procps-ng 4.0.6 `slabtop` command for the Batch 67 kernel-memory display milestone.

The command consumes kernel-memory observations and the reusable full-screen refresh lifecycle from `Icod.ProcPs.Shared`. Linux provides the authoritative kernel interfaces; unsupported hosts receive controlled diagnostics rather than synthetic data.
